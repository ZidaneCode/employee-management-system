# Employee Management System

A full-stack employee management application developed
using Spring Boot, Angular and Vue.js.

## Project Architecture

The project is composed of three independent applications:

- Backend: Spring Boot REST API
- Frontend Angular: Angular web application
- Frontend Vue: Vue.js web application

Both frontend applications communicate with the same REST API.

## Technologies

### Backend
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Spring Security

### Frontend
- Angular
- Vue.js
- TypeScript
- JavaScript

### Tools
- Git
- GitHub
- Docker
- Codex

## Main Features

- Employee management
- Department management
- Employee search and filtering
- Authentication and authorization
- Dashboard and statistics
